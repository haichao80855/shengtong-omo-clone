# 原系统证据规范

当前无原系统业务证据。待验证行不是黄金基线。

## 每次记录

证据 ID（E-模块-序号）、日期/构建、URL/路由、角色与组织/校区、浏览器/系统、视口/DPR/字体/语言/时区、夹具版本、操作步骤、前置状态、请求响应、可见结果及重查方式。证据可组合截图、Trace、脱敏 HAR、字段表和人工记录。

写操作登记环境与边界。看到按钮、客户端校验或模拟响应不能证明保存/扣课/权限规则；账号/环境不足保留未知。

逐字段记录标签、控件、默认值、枚举、必填、校验时机、边界、联动、错误文案和服务端拒绝；逐操作记录状态转换与跨页结果。结论标记已观察/推断/待验证/接受的偏差并关联工单。

权限登记「角色 × 页面/按钮/字段/API × 数据范围 × 结果」。不可访问页仍列为未覆盖，不能声称不存在。

## 文件与脱敏

会话、cookie、token、原始 HAR/Trace 和真实学员资料存本地忽略目录，不进入公共仓库。共享证据检查请求头/查询参数/正文/截图/下载文件/Trace附件，不能只用手机号正则判断完成脱敏。

一致占位 ID 与合成信息保留必要关系、长度和排版；原系统和复刻采用同一归一化规则。不可公开证据只登记受控位置和校验值，不泄露凭据。
