# ADR 001：证据决定复刻行为与范围

日期：2026-10-10。状态：采用（本次规划修复），具体业务仍待取证。

## 背景

原规划将没有可追溯证据的业务规则、单校区固定值、静态提取能力和全屏 5% 差异写成验收要求，可能导致实现偏离原系统。

## 决定

1. 原系统页面与业务前后结果为预期来源；HAR、AST、Mock 的证明范围分别登记。
2. 不预定单校区、角色枚举、手机号唯一性、扣课规则或课消不可逆。开发夹具不能省略需验收的上下文和权限。
3. 最小工程独立开始，AST/REA 不阻塞全部开发；保留技术方向，模型和契约随证据演进。
4. #2–#7 保留为父工单。候选实施工单 needs-evidence/blocked，证据与依赖满足后才提升就绪状态。
5. 保存旧规格/工单文本。本次未核验旧文自述的“三轮共识”，该自述不能替代证据或用户差异决定。
6. 切片即时验收视觉/业务/权限；最终检查所有页面，不能以代表链路替代全模块覆盖。

## 后果

无法采集的角色、写入或页面保持未知，对应能力暂缓；其他证据充分的切片独立推进。范围变化、外部替代与偏差需要可追溯决定。
