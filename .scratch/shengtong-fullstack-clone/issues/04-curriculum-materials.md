# 04: 教研标准课程库与编程教学素材管理垂直切片

**What to build:** 实现教研模块下的“课程管理”与“编程素材”全链路。从教研主管与授课老师视角，能够按科目层级树（少儿编程、机器人等）分类查看和维护标准教研课程模板，配置建议定价、总课时数与授课形式（班级课/1对1）；在编程素材库中能够按标签检索工程课件，支持上传本地素材（Scratch .sb3、Python .py 等）并支持文件下载与详情查看。

**Blocked by:** 02: 校区门户选择与工作台综合看板垂直切片

**Status:** ready-for-agent

- [ ] 提供科目分类树与标准教研课程列表，支持关键字模糊检索与分页展示
- [ ] 支持新增与编辑标准化教研课程，对课程名称、课时数、建议价格进行表单强校验
- [ ] 提供编程素材管理面板，展示素材名称、关联科目、文件类型、上传时间与大小
- [ ] 支持本地编程素材文件上传至服务端存储，并支持文件安全下载与详情预览
- [ ] Playwright E2E 测试覆盖课程新增与编程素材上传、下载的全流程验证
