# 02: 校区门户选择与工作台综合看板垂直切片

**What to build:** 实现系统的入口门户与全局工作台。从校区管理员视角，访问系统根路径时自动进入校区选择卡片列表，展示校区运营状态与详细信息；点击卡片无缝进入工作台，顶栏高亮显示当前校区标签；在工作台主看板上直观查阅在读学员总数、开设课程数、本周排课次和可用教室等核心运营统计指标，并浏览近期的授课日程动态与快捷操作入口。

**Blocked by:** 01: 全栈 Monorepo 基础工程骨架与离线逆向契约套件

**Status:** ready-for-agent

- [ ] 访问系统入口自动渲染校区选择门户页，展示旗舰校区卡片（名称、电话、营业状态）
- [ ] 点击“进入工作台”平滑切换到主管理后台，全局顶栏正确回显当前校区标识
- [ ] 工作台顶部卡片准确展示在读学员、开设课程、本周排课、可用教室统计指标
- [ ] 工作台看板下方列表展示近期的排课日程动态，并提供快捷导航跳转入口
- [ ] Playwright E2E 测试覆盖从门户选校到进入工作台并成功渲染统计指标的全链路
