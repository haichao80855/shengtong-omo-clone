# 06: 校区售卖课程包装与班级排课冲突检测垂直切片

**What to build:** 实现教务模块下的“售卖课程”包装与“班级课次”日历调度全链路。从教务排课老师视角，能够将教研模块中的标准课程包装为校区专属的“售卖课程”（配置实际定价、有效期天数与赠送课时）；能够创建教学班级并指定任课教师；能够在日历视图上排定具体课次、选择授课时间段与物理多媒体教室；当选择的教师或教室在重叠时间段已被占用时，系统即时计算并弹出冲突阻断提示，防止排课撞期。

**Blocked by:** 03: 系统机构资料与教学场地管理垂直切片, 04: 教研标准课程库与编程教学素材管理垂直切片

**Status:** ready-for-agent

- [ ] 提供校区售卖课程管理列表，支持从标准教研课程选择模板并配置定价、课时包规格与售卖开关
- [ ] 提供班级管理列表，支持新建班级并绑定售卖课程与任课教师
- [ ] 提供班级排课与日历课次视图，直观展示排定的日期、起止时间段、授课班级、教师与教室
- [ ] 排课时执行教师时间冲突与物理教室占用重叠算法校验，冲突时弹出明确拦截警示并阻止保存
- [ ] Playwright E2E 测试覆盖售卖课程发布、班级开班、日历排课以及排课冲突拦截验证
