# 05: 学员档案、电子钱包与 Excel 批量导入垂直切片

**What to build:** 实现学员模块下的“学员管理”、“电子钱包”、“学员异动”与“学员导入”全链路。从教务老师与财务人员视角，能够分页查阅全校学员档案，支持姓名/手机号模糊搜索与多状态（在读/结课/流失/潜在）Tab 快速筛选；支持录入新学员，触发严格的 11 位手机号格式校验；展示学员电子钱包余额及充值、扣款资金流水明细；支持学员异动（转班、休学、退费）；提供标准 Excel 模板下载与批量导入解析，自动拦截手机号重复行并回显错误。

**Blocked by:** 02: 校区门户选择与工作台综合看板垂直切片

**Status:** ready-for-agent

- [ ] 学员列表展示姓名、手机号、状态、创建时间及所属校区，支持分页与模糊检索
- [ ] 支持按“全部/在读/结课/流失/潜在”状态 Tab 筛选列表
- [ ] 新增/编辑学员弹窗严格校验必填项与 11 位合法手机号格式
- [ ] 学员详情页展示电子钱包账户余额、充值记录流水与消费扣减明细
- [ ] 支持办理转班、休学与退费异动，异动后学员状态及变动日志正确记录
- [ ] 提供学员导入 Excel 模板下载，支持上传 .xlsx 批量导入，重复手机号正确阻断并回显错误
- [ ] Playwright E2E 测试覆盖学员创建、状态切换、钱包流水查看与 Excel 导入校验全链路
