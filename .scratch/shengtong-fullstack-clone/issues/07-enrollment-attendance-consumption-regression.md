# 07: 选课报名、点名考勤、自动课消课评与离线黄金回归闭环

**What to build:** 打通全系统核心业务中枢状态机闭环与终验回归套件。从教务老师与任课教师视角，教务老师可为学员办理课程报名、选购校区售卖课程、关联内部支付方式（现金/转账/POS）并自动划拨学员课时与钱包变动；任课教师在授课前查阅教学服务课次动态，进行学员点名签到；点名确认后系统自动触发课消状态机，原子扣减到课学员对应课程的课时账户并记录课消流水；教师完成课后评价与学员打分；最后运行覆盖全部 6 大主业务场景的 Playwright 离线 1920x1080 视觉黄金快照（Pixelmatch ≤5%）与 DOM 契约综合回归测试。

**Blocked by:** 05: 学员档案、电子钱包与 Excel 批量导入垂直切片, 06: 校区售卖课程包装与班级排课冲突检测垂直切片

**Status:** ready-for-agent

- [ ] 学员报名选课弹窗支持选择售卖课程，登记合同金额与支付方式，报名成功后自动给学员账户充值有效课时
- [ ] 教学服务模块展示待上课课次日程，支持任课老师进入课次点名面板
- [ ] 点名面板支持标记学员考勤状态（出勤、请假、旷课），支持批量点名与单独点名
- [ ] 提交点名后自动触发课消状态机，出勤学员的剩余课时原子扣减，生成不可逆课消历史明细
- [ ] 支持针对已课消学员填写课堂表现评价、技能掌握打分与评语
- [ ] 运行 Playwright 离线黄金比对套件，覆盖门户、看板、机构、教研、学员、排课课消全业务链路，断言视觉快照与 API 契约完全符合验收标准
